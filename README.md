# 🐾 Pet Adoption Website (AdoptHere)

A modern and responsive pet adoption web application built using React + Vite.

The goal of this project is to help users browse pets and adopt animals easily through a clean and interactive UI.

---

## 🌐 Live Demo

👉 https://naserddinekaren-source.github.io/pet-adoption/

---

## 📌 Features

- 🐶 Browse pets by category (Dogs, Cats, Birds, Rabbits, Ducks)
- ❤️ Favorite pets system
- 🛒 Adoption/cart feature
- 📱 Fully responsive design (mobile + desktop)
- 🎨 Modern UI with custom styling
- ⚡ Fast performance using Vite

---

## 🛠️ Technologies Used

- React.js
- Vite
- React Router DOM
- JavaScript (ES6+)
- CSS
